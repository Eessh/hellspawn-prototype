# Replay truth = starting snapshot + saved inputs, nothing else

A run is reproduced from its starting world snapshot plus its saved inputs: user commands, recorded external answers, random seeds, and config choices — kilobytes, not gigabytes. Everything the sim produced internally (emitted events, transitions, reservations, metric samples) belongs to the diagnostic trace, which explains causality but is never the replay source and can be sampled or regenerated. Everyday viewing of a finished run is Playback of a saved movie (ADR-0030); engine replay is an engineering tool. Optional video capture is an attached artifact, never truth.
