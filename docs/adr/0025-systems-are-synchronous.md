# Systems are synchronous — no await, no network, no clock, no random inside the core

Replay works by re-running the sim from saved inputs, so the core must give the same result every run. An `async` system means answers land whenever the network feels like it, so event order changes between runs and replay dies. Therefore: every System is a plain synchronous function. It may only read the world, write staged changes, and emit events. Talking to the outside world = emit a request event; an adapter (outside the core) does the real I/O and the answer comes back as a normal event — in Pure Simulation Mode from a mock service after its configured delay, in the live modes stamped with the sim time of its real arrival (ADR-0026). Banned inside systems: `async/await`, network calls, `Date.now`, `Math.random` (use the engine RNG, ADR-0019).
