# Periodic checkpoints, not only scenario boundaries

Checkpoints at scenario boundaries only (ADR-0008) mean a mid-run crash loses the whole run — fatal for Live mode, where replay cannot recover because the real external world moved on. The worker therefore also checkpoints on a configurable cadence (every N sim-minutes or M events), with exactly the boundary-checkpoint content: component state, event queue, RNG state, run metadata, external interaction cursors. A crashed Live run resumes from the last checkpoint and is marked recovered with an honest gap. Bonus uses: replay can seek — jump to the nearest checkpoint before a moment of interest and re-run forward instead of from the start — and a playback keyframe is a checkpoint minus queue and RNG, so one serializer feeds both.
